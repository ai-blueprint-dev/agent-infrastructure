What is claude -p?

It's how you ask Claude Code to do one thing and stop. You hand it a complete instruction (the prompt), Claude does the work, shows you the result, and quits. No back-and-forth, no "anything else?". Done.

That's exactly what these skill cards are: complete instructions. Click a card → it copies the full command. Paste it in your terminal → Claude runs it → you watch the result come in. The dashboard is the menu; your terminal is where the food gets cooked.

When to use what

  1. The dashboard cards (which use claude -p) — best for the routines on this page: morning brief, inbox triage, weekly digest. You already know what you want; just run it.
  2. Just type claude in a terminal — opens a normal chat with Claude. Use this when you don't quite know what you want yet, or when you want to keep going after the first answer ("now make it shorter", "redo that with bullet points", "save it somewhere else"). It stays open until you close it.
  3. The Claude Code extension in VS Code — same Claude, but inside your code editor. Use this when you're actually working on code and you want Claude to read and change your files. You see every change as a side-by-side diff and can approve or reject each one.

So when you click a card here, nothing happens automatically — it just copies the command for you. You're still the one who chooses to run it. That's on purpose: you stay in control, you see exactly what gets run, and the result lives in your terminal where you can scroll back through it.

Cards with a small {input} badge in the corner are templates that need a piece of input from you — a topic, a question, a note. After you paste the command, find the word {input} inside it and replace it with whatever you want before pressing Enter.
